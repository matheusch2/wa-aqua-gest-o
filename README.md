# WA Aqua Gestão

Sistema de gestão de viveiros de camarão: manejo, biometrias, ração, custos e relatórios de ciclo. Aplicação estática servida pelo GitHub Pages com suporte a PWA e serviços de backend no Supabase.

- [Arquitetura e caminhos públicos](docs/arquitetura.md)
- [Histórico de verificação dos scripts SQL](banco/LEIA-ME.md)
- [Funções de backend](supabase/functions/LEIA-ME.md)
- [Orientações para contribuir](AGENTS.md)

Para desenvolver, use Node e npm. Rode `npm test` para a suíte e, com as dependências de desenvolvimento instaladas via `npm ci`, `npm run verificar` para o lint. Para navegar localmente, sirva a raiz com um servidor HTTP estático.
