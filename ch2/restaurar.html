🔄 Restaurar backup — WA Aqua

Transforma o arquivo wa-aqua-backup-….json em um comando SQL pra recolocar os dados no banco. Tudo acontece aqui no seu aparelho — nada é enviado pra internet.

Leia antes: isto restaura os dados do app (viveiros, rações, custos, etc.). Não recria os logins (a lista de e-mails/senhas fica no sistema de login do Supabase, à parte). Use quando os dados forem apagados/corrompidos mas o projeto ainda existir. Em dúvida, me chame no chat antes de rodar.
Como aplicar no Supabase
  1. Abra o painel do Supabase e entre no seu projeto.
  2. No menu, clique em SQL Editor.
  3. Clique em Baixar aqui, abra o arquivo restauracao.sql e cole todo o conteúdo (ou use Copiar).
  4. Clique em Run. Espere terminar — pode levar alguns segundos.
  5. Se aparecer erro na linha session_replication_role, me mande o print no chat que eu ajusto.
